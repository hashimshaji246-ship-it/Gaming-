Playroom booking app (installable web app)

1. Put all files in this folder on any web host (Netlify Drop, GitHub Pages, Firebase Hosting). It must be served over https.
2. Open the link on a phone: Android Chrome > Install app; iPhone Safari > Share > Add to Home Screen.
3. Staff PIN is 1234. Change PIN in index.html (search PIN=).

Bookings are stored on the device that makes them. For bookings shared between phones, the next step is a hosted database (Supabase or Firebase).
